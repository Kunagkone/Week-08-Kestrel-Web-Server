รหัสนักศึกษา: 67030037 N (3 ตัวท้าย) = 037 = 37

1. การคำนวณเกจ์
Left = (N mod 4) + 1 = (37 mod 4) + 1 = 1 + 1 = 2
Right = (⌊N/4⌋ mod 4) + 1 = (⌊37/4⌋ mod 4) + 1 = (9 mod 4) + 1 = 1 + 1 = 2
Left = Right (ชน) → ใช้กฎ Anti-Collision: บวกเกจ์ขวาเพิ่ม 1 → Right = 3

ผลลัพธ์ (2, 3): เกจ์ซ้าย = Audio VU Meter, เกจ์ขวา = Retro 7-Segment

3. หลักการทำงานของ JavaScript
pollTelemetry() ใช้ fetch('/api/telemetry') แบบ async ทุก 150 ms (setInterval) แล้วแปลงผลด้วย res.json()
ส่ง data.channelA.percentage (Potentiometer จริง) ไป updateLeftWidget() และ data.channelB.percentage (จำลอง) ไป updateRightWidget()
updateLeftWidget(pct): แปลง 0–100% เป็นจำนวน LED 0–10 ดวง (Math.round(pct/10)) แล้วเปิด/ปิด class on (เขียว 1–6, เหลือง 7–8, แดง 9–10)
updateRightWidget(pct): ปัดเป็นจำนวนเต็ม 0–99 แยกหลักสิบ/หลักหน่วย แล้วเปิดเซกเมนต์ a–g ตามตาราง DIGITS
CSS transition และ drop-shadow ทำให้การเปลี่ยนค่านุ่มนวลและมีแสงนีออน; try/catch ป้องกันหน้าเว็บค้างเมื่อเซิร์ฟเวอร์ขัดข้อง
